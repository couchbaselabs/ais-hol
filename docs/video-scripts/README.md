# Video Scripts

One script per tab, ordered by the curriculum learning path (beginner → advanced).
Each script targets ~6 minutes of spoken content at a comfortable presentation pace.

## Structure

Every script follows this format:

```
# [Tab Title]
**Module:** [module name] | **Level:** [beginner/intermediate/advanced]
**Runtime:** ~N min | **Tab:** `tab-id`

## Hook
Opening question or problem that motivates the topic.

## Concept
The core idea explained clearly, no assumed knowledge beyond prior tabs.

## Demo Walkthrough
Step-by-step of what to do in the interactive tab.

## Code Deep-Dive
Key implementation details from the backend/frontend code.

## Key Takeaways
3-5 bullet points the viewer should remember.

## What's Next
Bridge to the next tab in the curriculum.
```
